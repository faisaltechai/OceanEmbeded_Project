# Demo Mode & SIH Jury Walkthrough

**Demo Mode** = the curated, coarse-resolution (1.0°, 6-date) regional dataset in
`data/demo/`, generated by `ml/inference/build_demo_bundle.py`, so the full experience
runs in seconds with no external data download. Every screen in the UI that shows this
data is labeled **"Demo / Prototype Dataset"**.

## 3–5 minute jury flow (matches the brief's section 69)
1. **Landing page** — "Satellite observations tell us what is happening at the
   surface, but much of the ocean's structure remains hidden below."
2. **Ocean Map** — Bay of Bengal / Arabian Sea toggle, surface SST layer.
3. **Depth slider** — move from 0m → 1000m, watch the reconstructed subsurface
   temperature field update.
4. **Click a location** → **Digital Ocean Profile** opens: predicted temperature vs.
   depth, with an uncertainty band.
5. **Compare** — OceanEmbed vs. synthetic-ARGO vs. synthetic-GLORYS on the same chart.
6. **Uncertainty** — toggle the uncertainty layer: "the system knows where its
   predictions are less reliable."
7. **Extreme Events** — a flagged subsurface anomaly, with its detection reason shown
   in plain language.
8. **Smart ARGO Guidance** — top recommended-observation points, each with a reason
   (high uncertainty / sparse coverage / strong anomaly).
9. **Explainable AI** — SST/SSS/SSH/currents/winds contribution bars (feature
   ablation).
10. **Validation** — actual RMSE/Bias/Correlation, OceanEmbed vs. climatology
    baseline, plus the independent ARGO comparison.

## What is/isn't in this demo build
Implemented and demoable today: all 10 steps above, backed by real computed numbers.
Not implemented (documented, not hidden): live real-time satellite ingestion, a
validated marine-heatwave/cyclone classifier, and full pan/zoom tile-based mapping
(the demo map is a grid heatmap at 1° resolution, not a slippy map).
